# Morris Lam Photography

Static rebuild of Morris Lam Photography, migrated from Squarespace (site expired Jan 2024).
Hosted on GitHub Pages with the custom domain in `CNAME` (photography.morrislam.com).

- Plain static HTML/CSS/JS — no build step, no Jekyll (see `.nojekyll`)
- Photos are the original Squarespace uploads, byte-for-byte: never cropped, rotated, filtered, or recolored
- Every change is a git commit: remove a page with one commit, restore it later with `git revert`
- Full migration records (audit inventory, page-text archive, QC report, image export) are kept with the site owner
